# reliable-agentic-rag-system
Designed and deployed a production-grade Retrieval Augmented Generation (RAG) system with hybrid search (BM25 + vector embeddings), Reciprocal Rank Fusion (RRF), and cross-encoder reranking to improve retrieval precision.  Implemented an agentic decision layer with tool routing,  multi-query retrieval, and self-healing retry loops.
